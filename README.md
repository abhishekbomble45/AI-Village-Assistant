# AI Village Assistant

AI Village Assistant is an AI-based application that helps village users with agriculture, education, government schemes, digital services, and general information.

## Technologies Used

- Python
- Flask
- Google Gemini API
- HTML
- CSS
- JavaScript

## Features

- AI-based question answering
- Marathi, Hindi and English support
- Simple and user-friendly interface
- Village-related information assistance

## Project Purpose

The main purpose of this project is to provide easy access to useful information for rural and village users through an AI-powered assistant.
